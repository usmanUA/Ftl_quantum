# Ftl_quantum

## Project Overview

This project covers key quantum computing concepts such as:
1. **Superposition** - Understanding quantum states and probability.
2. **Entanglement** - Developing circuits that demonstrate quantum entanglement.
3. **Quantum Noise** - Running simulations on real quantum computers to observe quantum noise.
4. **Deutsch-Jozsa Algorithm** - Implementing a simple quantum algorithm.
5. **Quantum Search** - Building a search algorithm with quantum speedup capabilities.

## Project Structure

Each concept is organized in `.py` files, with additional Jupyter notebooks for interactive exploration. You’ll find PDFs for detailed explanations and visual representations of each exercise.
